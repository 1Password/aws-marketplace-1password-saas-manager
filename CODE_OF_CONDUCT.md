# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Everyone who takes part (in issues, pull requests, discussions or any other
project space) is expected to follow it.

In short: be welcoming and respectful, assume good intent, accept constructive feedback gracefully,
and focus on what's best for the people using this project. Harassment, personal attacks, and
publishing anyone's private information are not acceptable.

## Reporting

If you experience or witness unacceptable behaviour, report it to the project maintainers at
**REPLACE-WITH-CONDUCT-CONTACT**. Reports are handled confidentially. Maintainers may remove, edit or
reject contributions, and may temporarily or permanently ban anyone whose behaviour they judge
inappropriate, following the enforcement guidelines in the Contributor Covenant.
